# Frogged Out — Frog Arena 2.5D (Godot 4.7, Web + LAN/Editor)

Многопользовательская 2.5D-арена про лягушек в коробке с гольф-полем, ортогональной камерой, механикой рогатки с любой точки экрана, 3 общими 3D-моделями лягушек, **спавном бонусов**, **тонущими кувшинками** и **сужающейся зоной**.

## Что нового во 2-м этапе (Stage 2)
1. **Гибридный сетевой режим (Web Gateway + Локальный запуск из Godot 4.7)**:
   - В браузере и при запущенном Node-шлюзе (`server/`) кнопка **«СОЗДАТЬ ЛОББИ»** создает выделенную комнату через `POST /api/rooms` и подключает игрока по WebSocket (`/ws/room/<id>`).
   - При прямом запуске из редактора Godot 4.7 (**F5**) или без запущенного Node-шлюза игра автоматически переключается в локальный WebSocket хост-режим (`start_local_host_lobby`), сразу создавая комнату и спавня игрока-хоста и ботов.
2. **Генератор 3D-бонусов на арене (`ArenaPowerUpSpawner3D.gd` + `ArenaPowerUpPickup3D.gd`)**:
   - **Аква-Щит (`SHIELD`)**: окружает лягушку голубой 3D-сферой и полностью блокирует следующее напрыгивание соперника сверху.
   - **Крылья Стрекозы (`DOUBLE_JUMP`)**: позволяют совершить второй прыжок прямо в воздухе для доводки траектории.
   - **Турбо-Пружина (`SUPER_SPRING`)**: увеличивает силу и высоту прыжка на **+35%**.
3. **Тонущие кувшинки (`SinkingLilyPad3D.gd`)**:
   - 4 угловые пружинящие платформы на диагоналях коробки (`(±4.2, ±4.2)`), которые подбрасывают лягушку, меняют цвет на янтарно-красный и уходят под пол на 3 секунды.
4. **Сужающаяся опасная зона (`ShrinkingZoneHazard3D.gd`)**:
   - Через 18 секунд после начала раунда безопасное кольцо начинает сжиматься от краев к центру коробки, нанося по `10 HP/сек` урона за пределами круга и подталкивая игроков к центру.
